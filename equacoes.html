Equações do 2º Grau

📐 Matemática ⏱ 18 min 📊 Ensino Médio

Equações do segundo grau aparecem em funções quadráticas, problemas de área, física (movimento) e em muitas questões de vestibular. Dominar a fórmula de Bhaskara e o discriminante resolve a maior parte dos exercícios.

1. Forma geral

ax² + bx + c = 0 , com a ≠ 0

a, b e c são números reais (coeficientes). a é o coeficiente de x², b de x e c o termo independente.

2. Discriminante (Δ)

Δ = b² − 4ac
  • Δ > 0 → duas raízes reais distintas
  • Δ = 0 → uma raiz real (raiz dupla)
  • Δ < 0 → nenhuma raiz real (raízes complexas)

3. Fórmula de Bhaskara

x = (−b ± √Δ) / (2a)

As duas soluções são:

  • x₁ = (−b + √Δ) / (2a)
  • x₂ = (−b − √Δ) / (2a)

Exemplo completo

Resolva: x² − 5x + 6 = 0

a = 1, b = −5, c = 6

Δ = (−5)² − 4(1)(6) = 25 − 24 = 1

x = [5 ± √1] / 2

x₁ = (5+1)/2 = 3    x₂ = (5−1)/2 = 2

Raízes: 2 e 3

Conferência: (x−2)(x−3) = x² − 5x + 6. Correto.

4. Soma e produto das raízes

Se as raízes são x₁ e x₂:

x₁ + x₂ = −b/a   |   x₁ · x₂ = c/a

Útil para conferir resultados ou montar a equação a partir das raízes.

5. Interpretação gráfica

A função f(x) = ax² + bx + c é uma parábola.

  • a > 0 → parábola “para cima” (concavidade positiva)
  • a < 0 → parábola “para baixo”
  • As raízes são os pontos onde a parábola corta o eixo x
  • O vértice tem x_v = −b/(2a)
💡
Dica de prova: antes de aplicar Bhaskara, veja se a equação é fatorável (produto = c, soma = b). Muitas questões do ensino médio têm raízes inteiras fáceis.
